# technicallyreal-promo

Shared "Our other apps" page for TechnicallyReal's WinUI 3 apps. Each app bundles this
as a git submodule; the page cross-promotes the publisher's Store and web apps
and automatically hides the app it is running inside (matched by package family name).

App data (names, blurbs, destinations, icons) is generated by `refresh.ps1` and committed
as static assets. Consuming apps fetch the public manifest when the promo page opens, then
persist the last successful manifest and icons in app-local storage. Bundled assets remain
an offline first-run fallback, so the page renders even when GitHub is unavailable.

The public generated manifest is also available at
`https://raw.githubusercontent.com/RyanEwen/technicallyreal-promo/main/Assets/PromotedApps/apps.json`.

## Consuming (per app, one-time)

```powershell
git submodule add https://github.com/RyanEwen/technicallyreal-promo external/promo
```

In the app's `.csproj`:

```xml
<Import Project="external\promo\PromotedApps.projitems" Label="Shared" />
```

Add a nav item (e.g. in `NavigationView.FooterMenuItems`) that navigates to
`TechnicallyReal.Promo.PromotedAppsPage`.

CI note: checkouts need submodules, e.g. `actions/checkout` with `submodules: true`.

## Updating the promoted apps

1. Add/remove Store product IDs in `ids.json` (optionally set a `blurbOverrides` entry to
   replace the auto-extracted first line of the Store description). Add web apps under
   `externalApps`, including a destination and a repository-owned icon URL.
2. Run `.\refresh.ps1` - it queries the Store's StoreEdgeFD endpoint and regenerates
   `Assets/PromotedApps/apps.json` plus the icon files.
3. Review, commit, and push the diff. Existing app releases receive the update the next
   time their promo page opens; bump the submodule only when shared page code changes.

`refresh.ps1` is the only thing that talks to the Store backend. The runtime only reads
the committed GitHub manifest and its icons, so Store endpoint changes cannot break
shipped apps.
